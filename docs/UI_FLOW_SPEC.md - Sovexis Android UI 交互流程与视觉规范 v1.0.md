# UI_FLOW_SPEC.md - Sovexis Android UI 交互流程与视觉规范 v1.0

## 概述
本文档定义 Sovexis Android MVP 的 UI 架构、页面流转和视觉风格。UI 实现采用 Jetpack Compose，遵循 Material 3 设计系统，但注入 Sovexis 特有的"数字主权"视觉语言。

**主题色**：由首席架构师·陵谦选定为 **深空青**（`#006D77`）与 **晨光橙**（`#FF9F1C`）作为辅助强调色。深空青代表信任、深邃与技术的冷静；晨光橙用于关键操作与主权提示，传递温暖与主动掌控感。

| 元素 | 规范 |

## 2. 导航结构

底部导航栏包含 5 个目的地：身份、保险箱、支付、凭证、设置。

---

## 3. 关键页面流程

### 3.1 首次启动：创建主账号
- 欢迎语与主权宣言。
- 引导设置别名。
- 触发 WebAuthn 注册。
- 生成主账号，进入主界面。

### 3.2 身份页面
- 主账号卡片：金色渐变背景，显示 DID 前缀、别名、生物绑定标识。
- 副账号列表：轮廓人形图标，别名，8 位唯一标识码。
- 悬浮按钮新建副账号。

### 3.3 支付页面
- 余额卡片。
- 支付表单：付款副账号选择器、收款方 DID 选择器、金额输入框（带实时限额提示）。
- “预览交易”底部抽屉，确认后生物认证签名。
- 交易历史列表。

### 3.4 保险箱页面
- 笔记列表，点击条目需生物认证解密查看。
- 新建笔记，保存时加密。

### 3.5 凭证页面
- 两个 Tab：“我的凭证”与“验证”。
- 我的凭证：卡片列表，可生成二维码。
- 验证：扫描或粘贴 JSON，显示结果。

### 3.6 策略面板（设置中）
- 选择副账号，分组折叠配置。
- 支付组滑动条。
- 导出/导入 MD。
