# PROJECT_OVERVIEW.md - Sovexis 项目起源与愿景

## 项目名称
Sovexis · 个人数字主权基座

## 创建者
ringform

## 项目起源

本项目始于一个朴素的疑问：**当所有的身份、数据、支付、社交关系都被中心化平台定义和定价时，普通人还剩下什么？**

从最初设想的“个人AI驱动的身份认证和信息传播工具”，到如今演化为一个完整的**去中心化数字主权运行时环境**，Sovexis 始终围绕一个核心信念：

> **定义权与定价权不应属于任何政治厂商。每一个个体都应拥有自己的数字身份、自己的加密保险箱、自己的支付通道、自己的AI代理人——无需许可，不可剥夺。**

## 项目愿景

Sovexis 不是一个应用，而是一个**协议生态**。

- 在个人设备上运行一个轻量级主权节点，管理去中心化身份（DID）、加密数据保险箱、可验证凭证和自主支付。
- 通过副账号体系实现隐私隔离与风险可控。
- 通过本地 AI Agent（管家副账号）实现自动化事务处理，降低使用门槛。
- 通过服务商适配层接入第三方数据、算力与法币服务，形成可竞争的自由市场。
- 最终，让每一个普通人都能在"协议即宪法"的规则下，夺回属于自己的数字主权。

## 当前阶段：Android MVP

**当前版本：Sovexis v2.1.0**

我们正在构建首个可运行的最小可行性产品，运行于 Android 15 设备，具备以下核心能力：

| 模块 | 功能 |
|------|------|
| 身份 | 主账号生物绑定（WebAuthn）、副账号 BIP-32 派生、隐身地址生成 |
| 策略引擎 | 副账号权限配置（JSON/MD）、冲突检测、操作前强制检查 |
| 支付 | 交易构造与 ECDSA 签名、模拟账本、策略限额约束 |
| 保险箱 | 端到端加密笔记存储（AES-GCM + HKDF）、Room 持久化 |
| 可验证凭证 | 凭证签发/验证、二维码分享、W3C VC 轻量实现 |
| 本地 Agent API | 供个人 AI 调用的 AIDL 接口，支持需索审批 |
| 服务商适配器 | 预留第三方服务接入接口（AI 模型、数据、法币） |
| TSS 阈值签名 | 2-of-2 阈值签名、蓝牙/局域网传输、密钥份额管理 |
| ZKP 零知识证明 | 身份验证隐私保护、选择性披露 |
| Sovexis Node | 个人加密网络节点（Win/Mac/Linux）、Noise IK 握手、加密分片存储、Wails GUI |

## 技术哲学

- **主权优先于便利**：任何功能不得以牺牲用户数据控制权为代价。
- **可验证信任**：开源、密码学证明，无需信任任何中心化实体。
- **协议即宪法**：治理规则由协议层硬编码，杜绝人为特权。
- **高约束成本设计**：违规在签名前被阻断，让犯错成本远高于守规成本。
- **成本最小化与市场驱动**：数据流与计算存储由竞争性服务商提供，Sovexis 仅做身份与支付路由。
